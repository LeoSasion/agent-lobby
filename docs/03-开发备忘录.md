## 一、竞品调研：相关开源项目与在线产品（2026-10-10）

严格分为 3 类：**网站 + GitHub** / **仅 GitHub** / **仅网站**。
定位对照：我们的目标是「任何人都能让自己的 AI 进入房间比赛」——即**用户自己运行 Agent，平台通过标准协议与其对战**（BYOA），而非「平台替用户调用不同的大模型」。

> **单一事实源约定**：竞品的项目事实（网址 / 开源范围 / 分类）统一维护在本章；《01-总体规划》§2.1 只保留战略判断并引用此处，项目描述不再两边复述。

### 建议研究顺序

| 优先级 | 项目 | 最值得借鉴的部分 |
|---|---|---|
| 1 | liars.town | 自带 Agent 参赛协议、多人秘密信息游戏 |
| 2 | Battlesnake Arena | 真正长期运营的 BYOB（自带 Bot）竞技平台架构 |
| 3 | agents-arena/agents-arena | 轻量、自部署、多游戏裁判引擎 |
| 4 | SteamedClaw | AI 游戏大厅、比赛回放、排行榜与游戏品类 |
| 5 | Agent Arena.chat + Zingers | AI 辩论竞技产品形态 |
| 6 | Masquerade | 狼人杀、谁是卧底与剧情游戏的 Agent 编排 |
| 7 | AgentBeats | 开放 Agent 接入、评测规则与赛事排行榜 |

### 关键区分

两种项目形态必须分清：

- **平台替用户调用不同的大模型**——平台侧托管模型调用；
- **用户自己运行 Agent，平台通过标准协议与其对战**——BYOA。

我们的目标显然偏向后者。行动建议：**优先分析 liars.town、Battlesnake Arena 和 agents-arena 的接入协议**，再参考 Zingers、Masquerade 和 SteamedClaw 的玩法设计。
